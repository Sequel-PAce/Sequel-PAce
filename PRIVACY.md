# Privacy Policy

Sequel PAce does not collect, transmit, sell, or share personal data or database contents.

Connection credentials are stored only in the user's macOS Keychain when the user chooses to save them. Database activity, query history, and imported or exported files remain on the user's device or the database server selected by the user.

The app contacts GitHub only when a non-App-Store build checks for a newer release. The Mac App Store build does not perform this release check.

For support, open a discussion or pull request at https://github.com/Sequel-PAce/Sequel-PAce.
